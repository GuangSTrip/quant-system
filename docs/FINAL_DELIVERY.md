## 持续运行

关浏览器不影响后台。网站、网关、行情、调度与看门狗由 Windows 任务维护。A 股仍依赖已登录的掘金仿真终端；断网、关机及券商故障影响交易能力。

内网 HTTP 没有证书拦截，但不提供传输加密。课堂共享登录仅用于已授权的模拟展示；仓库不携带密码。全新部署须自行配置凭证，不能继承本机账户。
