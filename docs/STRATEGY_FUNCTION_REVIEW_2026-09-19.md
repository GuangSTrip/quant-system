# 策略功能检查

范围：本地浏览器真实交互、源码检查与平台回归测试；未部署、未启动策略交易、未连接外部券商。

## 已复现并修正

- 打开历史回测时，顶部策略选择未同步；现在报告与选择同步。
- 从分钟切换到日线时仍显示旧报告／计划；现在清空旧结果及快照复用勾选，并更新默认名称。
- 未导入组合报告时持续显示“读取回测”；现在显示暂无报告、恢复办法，禁用导出；切回仓库研究后正常恢复。
- 组合报告请求失败与账户状态请求增加选择一致性检查，避免旧请求覆盖新选择；公开访客不再请求私有运行状态。
- A 股组合说明区分独立手工仿真通道与尚未接通的组合自动执行。
- 明确分钟历史库与参数回测的统计分母／平仓时点差异，没有擅自重写既有研究结果。

## 浏览器实测

- 分钟与日线切换，VWAP 配置入口；查看历史开盘突破报告后选择器同步。
- 从分钟报告切到日线后旧结果不可见。
- 本地 fixture 账号登录、打开 VWAP 报告、选择原快照重跑，返回持久化成功；之后退出登录。
- A 股组合最新导入报告不存在时明确报空，导出和自动启动不可用；恢复仓库报告后展示曲线指标。
- 157 项平台测试通过；构建成功。

## 仍存在的能力边界

- 分钟历史库与网页参数回测采用不同的成交模型与收益分母，现已明确提示，尚未统一引擎。
- 178 个日线组合可以查看已有报告；重新计算依赖 Python 与历史行情准备，网页没有完整一键重算流程。
- 分钟真实数据覆盖有限，港股/A 股示例含合成样本；本地测试不证明任意历史区间可获得。
- 12 类 ETF 候选主要通过 Python 批量研究，尚未全部纳入网页策略选择。
- 178 个组合都铺在一个选择框内，缺少市场/规则筛选与搜索。
- A 股组合自动调仓未接通；美港股外部实际自动成交仍需用户账户验收。
