# 课程研究界面简化

默认入口为 `#course`，课程任务按“选股、买卖、仓位、理由、扣成本效果”组织。

- 固定历史报告使用模块选择，不再要求用户从上百个组合名称中选择。所有选择仅匹配已有实验，不假装重新回测。
- 课程页的市场、频率、选股、买卖、仓位、风险、图表、对照和排序选项展开后，鼠标悬停或键盘聚焦每条会显示解释；策略规则还补充主要取舍和可能失效的场景。手机可在展开列表内查看当前解释。
- 课程高频对应每日检查买卖条件；低频对应更长周期调仓。月度选股与日级退出可以同时存在，因此分类依据实际决策规则。波动仓位可能每五个交易日更新，页面说明实际周期。
- 历史研究不读取账户、报价或执行信号；模拟计划移至独立执行页，带着原策略 ID 进入，不启动交易。
- 默认只显示一组收益、成本和曲线。理由、历史回放、压力结果及旧工具按需展开；最多三套同市场同区间组合对比。
- 费用按原报告显示。未存储的无成本回测、独立压力结果、逐笔原因不推算或补造；新增选股使用已有历史候选记录。
- 分钟短样本保留为进阶实验，预算收益与预算回撤使用统一分母。
- 排序限定同市场、同频率、同历史区间，可按累计收益、年化收益、最大回撤或正年化收益/最大回撤查看；末项以 1% 为分母下限，属于探索性偏好分数，不是独立验证。成交笔数帮助识别靠空仓获得低回撤的结果。
- 图表可叠加最多三套同市场组合，切换净值/回撤与参考对照。新增“初始流动性前 100 只，目标 80% 股票、买一次后持有”的固定篮子，沿用原回测费率及流动性限额。原流动性篮子会按月换股，继续单独标明。
- 三市场基金对照分别为 A 股华泰柏瑞沪深300ETF（510300.SH）、港股恒生指数ETF盈富基金（2800.HK）、美股 SPY。A 股使用用户已配置的 Tushare `fund_daily + fund_adj`，港股使用 AkShare/Sina `stock_hk_daily(adjust='qfq')`，两者均逐日覆盖各自完整研究区间。美股冻结 SPY 分红复权快照只到 2026-05-29，图中的策略与基金均截到同一天，并单独计算共同区间指标；完整区间指标仍在上方。港股前复权价的分红再投资口径尚未单独对账，不能宣称是精确总回报。各市场基金对照均目标 80% 基金、其余现金，第二日开盘买入一次，单边成本分别为 15/20/10 基点，并使用前日成交额 1% 的流动性上限。各市场的初始 100 万本币单独核算，不跨币种比较绝对成本或收益。
- 选定组合展示 2025 探索段与 2026 至今复核段的年化收益和最大回撤，清楚注明两段都已参与研究，不能充当真正未见样本检验。

## 保留的边界

本次是界面与信息组织调整，没有修改交易算法、下单逻辑、持仓归属或历史收益。旧实验入口及执行功能保留。原始档案缺少的逐笔指标与成交理由，需在研究环境有原数据时重新生成。无成本和不同调仓周期的完整重跑也不由页面切换代替。

固定篮子由 `scripts/build_course_benchmarks.py` 从原始价格面板生成，使用原研究的 `prepare` 与 `execute` 逻辑，但只执行首次买入，不再重选。不是追踪指数的 ETF；其样本选择仍有原始数据的存续和价格质量偏差。它提供“若不换股会怎样”的课程对照，不能替代宽基基金实盘历史。

地区基金抓取脚本为 `scripts/fetch_course_regional_funds.py`，只读访问本机已配置的凭据，不把 Token 写入结果；原始复权价格、来源和摘要保存在 `course-regional-fund-inputs.json`。SPY 使用已有 `classroom-snapshot.json` 冻结快照。三市场基金净值由 `web_platform/scripts/build-course-fund-benchmarks.mjs` 在本地生成，来源和原始摘要随结果保留。对照展示的是固定基金/现金比例的持有结果，而非把基金自身 100% 投入收益直接与最高 80% 股票敞口的策略对比。

## 验证

构建、产物校验和 Node 回归测试；浏览器检查三市场与课程频率、模块切换、组合对比、历史回放和配置进入执行页。研究期间只请求身份状态及固定报告，不请求券商账户／报价／实时信号。390px 手机布局无横向溢出。
