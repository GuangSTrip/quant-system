## 已实现

- 组合决策内核新增真实回测成交、现金及实际持仓记录；导入接口检查时序、权重、数量、成本和总笔数。沿用已有净值和交易规则，178 组合原黄金结果不变。

## 操作与复现

在「策略中心 → 高频 → 具体策略 → 历史回测报告」展开「调整参数 / 导入真实分钟行情 / 样本外检验」。改参数后点击重算，再看回放和检验表。HK/CN 整手、午间休市与 CN T+1 保留；市场约束不同不会被伪装为同一执行制度。

仓库根目录运行：

```sh
# 只读检查配置与缓存是否齐全，不显示密钥
.venv/bin/python scripts/check_classroom_readiness.py
# 获取新的公开短样本，保存在 Git 忽略目录；固定课堂快照不会自动被覆盖
.venv/bin/python scripts/fetch_public_classroom_minutes.py
# 使用原股票池缓存补算组合；缺失市场返回非零并输出 manifest.json
.venv/bin/python scripts/replay_portfolio_archive.py
# 三市场分段与成本检验，结果存入 reports/minute_research/comparison.json
node web_platform/scripts/evaluate-minute-research.mjs
```

分钟 JSON 最少字段：`market`（US/HK/CN）、`symbol`、`timeframe: "1Min"`、`sample_kind: "historical"`、`source`、`bars`（每根含带时区的 t 与 o/h/l/c/v）。单份最多 60,000 根、20 MB；合成数据必须标为 `synthetic`。
