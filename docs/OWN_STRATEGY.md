# 第 2 组自研策略：日内增强均值回归

在“选策略 · 开始模拟”选择美股，列表首项即为“★ 本组自研 · 日内增强均值回归（分钟）”。沿用统一策略入口，不另设导航。分钟策略与日线组合口径不同，不混入日线年化收益排名。

## 展示与操作流程

1. 阅读规则卡片：选什么、何时买、何时卖。
2. 查看筛选漏斗、股票名称、评分与未入选原因；可刷新最新 IEX 候选。固定历史教学池为 SPY、QQQ、AAPL、MSFT、TSLA、META、NVDA、AMZN、GOOGL，筛选窗口为 5 个完整交易日。不同数据源的成交量覆盖不同，结果不能直接比较。
3. 选择一只股票、预算与参数，运行历史回测。固定样本可离线复现，最新 IEX 回测需要有效行情权限。查看扣成本盈亏、预算收益、账户回撤、净值、逐分钟决策和逐笔成交，并下载完整 JSON。
4. 登录后保存回测，核对股票、预算和参数，再确认模拟启动。更改设置会清除旧报告的启动资格。回测与查看记录均不下单。
5. 后台检查最新行情，遵守现有风控、订单幂等及持仓归属约束。实际订单按券商累计成交记账，不以提交成功替代成交；保留已有持仓。页面展示当前状态、过去运行、订单成交和最近检查，可暂停、恢复、手动检查。

## 默认规则与实现

以经典 VWAP 均值回归为基础，结合候选筛选、下跌护栏、时间止损和成交对账。

- 候选筛选：价格 >5 美元、日均成交额 >5 亿美元、估计价差 <5 基点、尾盘波动比 0.5–2；流动性/成本/波动稳定性权重 50%/30%/20%。价差由分钟成交价格估算，不是真实盘口报价。
- 美东 10:00 后，当价格比日内 VWAP 低至少 60 基点，且前 20 棒累计收益不低于 −1.5 倍分钟收益均方根时允许入场。仅做多，每天最多一次入场。
- 价格回到 VWAP、持有满 60 根有效分钟棒，或收盘前 15 分钟窗口触发退出。时间止损不是固定亏损比例；数据缺口时 60 棒可能长于 60 分钟。
- 回测信号用下一棒开盘成交，日终处理剩余仓位；单边成本默认 10 基点。在线用限价模拟委托、券商成交回报对账，交易日历辅助处理提前收盘，跨日未平仓优先处理。
- JavaScript 核心：`web_platform/src/intraday-kernel.mjs`；筛选：`universe-kernel.mjs`；在线执行：`automation.mjs`。Python 离线对照：`quant_system/intraday.py`。
