# 策略验证规范

## 验证门禁

默认研究报告要求：

1. 未参与选参的留出集总收益为正。
2. 留出集 Sharpe 高于 0.5。
3. 所有配置的成本压力场景仍为正收益。
4. 至少三分之二 walk-forward 折为正收益。
5. 区块 Bootstrap 中年化收益为正的概率至少 70%。
6. 候选策略或参数数量校正后的折损 Sharpe 概率至少 50%。

统一基准还要求：所有候选使用同一数据、成本、风险和执行模型；只按开发集选择一个候选，再报告其留出集结果。完整样本最佳策略不能被称为样本外赢家。

门禁通过只是进入模拟盘的必要条件，不是收益保证。真实数据还必须处理：退市标的、指数成分历史、复权、时点数据库、币种与税费，从而控制幸存者偏差和时间穿越。

## 防止研究者过拟合

- 参数评分同时惩罚回撤和换手，不只最大化 Sharpe。
- 网格应稀疏且来自经济假设；避免数千组无依据搜索。
- 记录所有尝试，不删除失败实验。
- 关注参数邻域平台而非单个尖峰。
- 最终留出集一旦看过，不再属于真正样本外数据。
- Bootstrap 使用连续区块抽样，保留部分波动聚集和序列相关。

## 收益目标

高收益必须与承担的风险、容量和杠杆同时陈述。优先顺序是：数据可信 → 样本外为正 → 成本后为正 → 尾部风险可承受 → 才讨论提高收益。提高杠杆只能放大已有期望，也会同步放大回撤和模型误差。
