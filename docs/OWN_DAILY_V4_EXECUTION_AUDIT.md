# 成交审计补充

核查最终候选与同口径旧策略的每笔成交：A股、美股均未发现当日量为零而成交；港股候选20笔、旧策略28笔涉及当日记录量为零、开盘价仍存在的日期。原引擎只检查前一日量和当日开盘价，缺少当日有成交的必要条件。

修复为当日必须有正成交量；当日成交量只作为事后确认能否成交，不进入当日之前的选股信号或成交容量（容量仍使用此前成交额）。这些数据可能是源数据问题，也可能是停牌/休市，不能假定有可靠成交。

原港股基础和账户风险结果分别保存在`HK_before_execution_fix`和`risk/HK_before_execution_fix`，仅用于审计，退出最终结果。相同配置、开发期选择规则在修复后重跑；不是重新搜索新参数。A股、美股最终成交审计无此问题，其冻结结果保留。

`scripts/audit_own_daily_fills.py`检查最终三个市场候选及旧策略对照，保存`FILL_AUDIT.json`。本补充不会解决港股复权和历史股票池问题。
