# 三市场当前日线策略：动态股票池与订单门禁

课程模拟账户从空仓开始，每个市场各用 100 万本币：A 股为 CNY、港股为 HKD、美股为 USD。目标为**年化收益至少 8%、最大回撤不超过 5%**。这是目标，不是已有业绩；旧固定名单的 36 个选股与仓位组合没有一个在完整历史中同时满足这两个条件，新股票池尚未完成可靠的历史回测。

## 固定名单已退出当前策略

网站日线页改为 `current-daily-plan.json`，旧 `daily-library.json` 不再加载或作为网站接口提供。旧报告和 `expand_daily_universe.py` 保留在本地供历史审计，不影响当前选股、目标仓位或订单判断。

当前 A 股流程是：Tushare `stock_basic` 上市名单 → 最近完整交易日的全市场 `daily` → 剔除非沪深、上市不足 180 日、当时仍带 ST 名称、无成交股票 → 按该日成交额动态取前 100 只高流动性股票 → 拉取各自 2025-08 起日线与复权因子 → 120 日趋势、约 6 个月动量除以 60 日波动率选前 5 → 按预测组合波动率 6% 调整仓位 → 剔除在 100 万元账户中目标仓位买不起一手的股票并重排。每一步代码在 `scripts/generate_current_daily_plan.py`。这仍只是当日决策管线：以最新成交额选出的 100 只做历史回测会有事后选择偏差，不能用它证明 8%/5% 目标。

## 更新命令

在 `quant-system` Conda 环境、项目根目录运行：

```powershell
python scripts/generate_current_daily_plan.py --limit 100
python scripts/build_current_daily_web.py
cd web_platform
npm run build
```

待 A 股 2026-09-18 完整收盘日线上线后重跑，信号才可用于下一交易日的模拟订单计划。本地演示服务会从磁盘读取最新 JSON；若构建可移植发布包，则需运行 `npm run build`。策略研究只给出选股、目标权重及买卖意向；模拟盘连接仍由课程项目负责执行的组员处理。

本地已启动一次性的只读收盘后刷新任务：2026-09-18 17:10（北京时间）开始查询当日完整日线，若尚未入库则每 5 分钟重试，最多至约 18:30。当前本地演示服务会从磁盘读取最新计划，刷新浏览器即可看到更新结果；运行与错误日志分别在 `reports/current_daily/refresh.out.log`、`reports/current_daily/refresh.err.log`。这个任务不提交券商订单。
