# 第二轮预登记：改变机制，而不是无限细调参数

2026-09-22。在已看到第一轮部分下载样本的结果后登记；因此本轮后期结果仍属于回溯研究，不升级为真正未接触的样本外。

第一轮只优化仓位强度和持仓数量，不能证明20%年化/15%回撤。港股只有平台额度内的小样本，持仓覆盖偏低；美股样本中的下行风险与退市/停牌处理明显影响结果。先扩充数据，再检验下述24个固定组合，不删除失败试验。

## 评分

所有横截面分位数都在当时流动性合格池中计算。

- 动量 M = 25%×63日（跳5日）分位 + 45%×126日（跳5日）分位 + 30%×252日（跳21日）分位。
- 趋势质量 Q = 50%×126日路径效率分位 + 30%×低下行波动分位 + 20%×低单日涨幅集中度分位。路径效率为126日日志收益之和/绝对日志收益之和；集中度为63日最大正收益/63日正收益之和。它们是价格形态指标，不冒充财务质量。
- 原型：65%M+35%Q。
- 高点型：55%×接近252日最高价分位+25%M+20%Q。
- 状态型：强势市场用75%M+25%Q；中间状态用55%M+25%×近期5日收益接近−2%的分位+20%Q；两者用市场广度40%—65%间线性权重混合。假设是上涨广泛时偏趋势、上涨较窄时偏趋势内轻微回调，必须验证，不能当作已知事实。

股票仍须高于120日均线且中期动量为正。现有持仓得到0.03的排名保留加分，减少边缘排名反复换手。持有最多15只，单只目标最多10%，不把不足的持仓数量强行补成满仓。

## 风险与执行

市场广度=合格股票中高于200日均线的比例。25%以下目标股票敞口为零，25%—70%线性恢复；此机制有滞后和错过反弹的代价。逆波动权重，再用最近60日组合共同波动缩减股票敞口；目标年化波动18%或24%，目标股票敞口最多95%。目标波动不是最大回撤保证。

候选与已选股票120日相关系数超过0.85时跳过；这不是行业中性，也不能替代行业集中度数据。

调仓频率5或21个市场交易日。退出规则比较不开启与持仓收盘价从持仓期间最高收盘价跌10%后退出，退出信号次日执行，20交易日内不重买该股票。隔夜跳空可能超过10%，不能把它称为亏损上限。市场广度跌破下限也产生次日调整信号。

组合：3评分×2目标波动×2频率×2退出规则=24组。固定开发期评分：CAGR−2×max(最大回撤−15%,0)−0.10×max(20%−平均敞口,0)。仅按开发期评分选主候选，不根据全段最优重选。留出/压力结果差也照常发布。

## 成本来源与假设

- A股佣金假设万三、每笔最低5元；卖出印花税2023-08-28前千一、之后万五；过户费以2022-04-29前十万分之二、之后十万分之一计，单边滑点5bp。佣金假设包含常规经手监管成本，未声称复刻用户券商套餐。
- 港股佣金假设万三、最低3港元，平台费每笔15港元；股票印花税在2021-08-01—2023-11-16为0.13%，其他研究日期0.1%，向上取整至港元；交易费2023年前0.005%、之后0.00565%；SFC 0.0027%、2022年起AFRC 0.00015%；结算预留为max(2港元,成交额0.01%)，属于保守假设；2023年前另计0.5港元交易系统费；单边滑点10bp。
- 美股按Alpaca零佣金假设；卖出成交额1bp作为监管费保守预留，不声称精确复刻历年SEC/按股数TAF；单边滑点10bp。
- 三市场全部成本加倍重跑；最低费用也加倍。逐笔保留commission/tax_exchange/slippage字段，期末持仓扣卖出费用准备金。费用不能只在最后从年化里随意减一个百分点。

早期A股过户费统一使用上述比例，是模型近似，尚未逐年复刻所有早期按股数/面额的收费变化；股息个人所得税/跨境预扣税也没有从供应商复权序列单独还原。这里“扣成本”指扣除已列明的模型交易费用，不是个人账户最终税后收益。
