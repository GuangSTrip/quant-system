# 跳出原策略：第五轮机制对照

2026-09-22，先登记后运行。当前全部历史均已被前期研究接触，因此仍是探索；不声称未接触样本外。

## 为什么改变方向

原有候选主要是横截面动量/低波动评分、广度择时与止损的不同组合。降低仓位压住部分回撤，但没有证明存在足够强的收益来源。本轮改选股逻辑，不再扩大旧参数网格。

## 可直接用当前数据检验的四类组合

共同：各市场独立；初始清单不按最终赢家缩减；过去20日成交额前500且60日年化波动率≤75%；沿用历史数据、费用与成交约束；只做多、不借款。目标波动率只测试14%和20%，共每市场8个固定配置。

1. **短期残差反转**：用上日成交额合格且已有20日数据的流动性前500只的当日等权收益构造市场代理，126日回归估计beta（滞后1日），过去5日残差和除以前5日之前60日残差标准差×√5。交易候选仍需252日预热。只买z在−3至−0.5之间、最近5日单日绝对涨跌小于20%的25只最弱股票；市场广度低于35%时不建仓。每5日调仓，逆波动配重、单股≤10%。假设为暂时流动性冲击的修复；尚未排除财报和行业冲击，不能称严格流动性套利，也不能保证均值回归。
2. **长期落后后的转强**：从63日前到252日前的收益最弱者中，选择最近63日上涨且站上120日均线的25只。每21日调仓，逆波动配重、单股≤10%。假设为较长期定价修复；价格落后不等于基本面便宜，明确不是价值因子。
3. **分散时序趋势**：不按过去涨幅挑赢家；按当时成交额选最多100只站上200日均线且20日均线高于120日均线的股票。每21日调仓，逆波动配重、单股≤2%，不足部分持现金。检验分散、各股票自身趋势是否优于横截面赢家集中。
4. **固定多机制组合**：50%分散趋势+25%短期残差反转+25%长期转强；每5日调仓，整体风险目标只减仓。固定权重不按全段相关性最优化。三者仍然都是股票多头，不能预设熊市负相关或市场中性。

初始资金100万本币，最高目标仓位95%，估计波动率超目标时同比减仓。下个开盘执行，手续费、税费、滑点、停牌、已匹配公司行动、成交容量及期末卖出费用准备金沿用修正账本。未决持仓不当现金，另测零回收压力。

## 评比

仍按截至2020年的既定评分选择，保留8个全段结果，另列2021—2023、2024—2025。对主候选做费用加倍、成交再延后一天、零回收压力。把上轮最终候选在同一引擎和数据上重跑作基线。任何组合不能仅凭全段最好成绩被命名为最终方案。

短期反转尤其受费用影响；若毛收益有而扣费消失，应淘汰或重新设计执行，而不是删除成本。对固定混合组合另列组成机制日收益相关性作为诊断，不能反过来用其挑全段最优权重。

## 需要额外数据的真正新信息

- 盈利质量/现金流/估值：必须有历史披露时间与可得版本，不能把今天修订后的报表提前填回历史；三市场需要分别落实数据来源。
- 财报事件与预期差：需披露时间、历史市场一致预期及事件后可成交价格。只有日线不能伪造盘前/盘后公告优势。
- ETF多资产配置：若研究范围允许，可引入债券、黄金等不同资产，另核查各市场上市日期、币种、费用与可交易历史。不能将跨资产期货研究的业绩直接套到本地ETF。
- 配对/市场中性：需历史借券可用性、借券费和做空限制。当前现金多头模型不能通过记负仓位宣称支持。
