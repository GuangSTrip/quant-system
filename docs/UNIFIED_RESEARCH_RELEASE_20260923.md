## 展示与合并原则

同页提供五个清楚可见的选项：教学组合与分钟策略、本组日内增强回归、日线风控、反转与趋势、财务质量。V1–V3 作为早期研究沿革保留，V4 基础/风控、V5 替代策略以及 A 股财务方案展示对应的选股规则、费用、历史阶段、压力测试、历史决策与逐笔成交。

10 份研究快照按选择加载，共约 19.2 MB，不放入浏览器首屏脚本。来源是已有研究结果，不重新选择最优全样本收益；导出脚本记录相对来源路径与 SHA-256，完整研究 JSON 可下载。

新增日线研究采用复权分数单位和最高 95% 股票敞口，与当前在线组合的整手及 80% 上限不相同，因此保持“历史研究、尚未接入自动交易”状态，不伪造实时信号或增加下单按钮。研究目标未验证、历史数据缺口和已观察后续年份的限制在页面说明；股票名称缺失时明确标记，不猜测名称。
