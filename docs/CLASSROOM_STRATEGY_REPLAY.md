# 策略课堂演示：历史运行 → 决策 → 成交 → 总览

更新后的统一引擎、真实三市场分钟样本和参数检验能力见 [补全状态](STRATEGY_COMPLETION_STATUS.md)。下文保留原课堂路线。

## 建议演示路线（约 5 分钟）

1. 打开本地网站，进入左侧「策略中心」，选「低频 · 日线」→「双均线趋势」。默认展示「历史回放与总览」，无需登录或连接券商。
2. 先介绍全样本收益、最大回撤、成交笔数、初始资金与成本；展开「策略规则与回测假设」说明 10/30 日均线、30% 仓位、单边成本 10 基点。
3. 点「回到起点」，再点「下一笔成交 / 调仓」。说明：本时点开盘成交来自前一根完整行情的信号；页面另列本时点收盘决策，用于随后执行。现金加持仓市值等于该时点净值。
4. 用日期框跳到 2024-08-05，或拖动时间轴。绿色净值、蓝色基准、回撤曲线只画到当前观察时点。顶部总览始终统计全样本，不随时间轴重算。
5. 切换「绝对动量」「买入持有」，比较规则、曲线、成本与决策。三种策略预热长度不同，报告明确显示各自的实际回测起止日期。
6. 切换「高频 · 分钟级日内」→「VWAP 均值回归」，选择美股 SPY。点击下一笔成交，观察买卖信号时间、成交时间、VWAP / 触发线及成本。
7. 点「查看完整结果」→「导出课堂报告 HTML」。报告包含全区间走势图、参数、决策明细及成交记录，可离线打开并由浏览器打印为 PDF；若内嵌浏览器未自动保存，可点击生成的保存链接。

## 覆盖能力与不可混淆的边界

| 类型 | 历史走势图 | 逐时点决策 | 数据与限制 |
| --- | --- | --- | --- |
| 双均线、绝对动量、买入持有 | 有 | 有：价格、规则数值、现金、持仓、成交 | SPY 冻结复权日线；750 根输入，来自 SHA256 校验过的课程原始数据 |
| 开盘区间、VWAP、自适应动量 | 有 | 有：每根分钟线、触发数值、持仓、成交 | 美股 SPY 为 5 日历史快照；港股/A 股也已换成约 5 日真实短样本；仍不足以评价长期有效性 |
| 参数化回测 | 有 | 新生成报告有，旧报告按其实际档案显示 | 仍需要相应行情；访客的冻结演示不依赖券商登录 |
| 178 个日线组合旧报告 | 有 | **未保存，不推造** | 只可回放已存档净值；成交总笔数与逐笔记录是两回事 |
| 新导入的日线组合重放 | 有 | 有：每日是否重算与收盘目标权重 | 用更新后的 `portfolio_signal.py` 重跑；目标不是实际成交持仓，缺失原始历史数据仍须先补数据 |

分钟研究库的三种美股策略已与参数化回测共用引擎、10 万账户收益口径和收盘前 15 分钟退出规则。港股与 A 股共用信号规则，执行保留整手、交易时段和 T+1 等市场限制。

日线示例复权包含股息效应，不另计分红现金。蓝色日线基准未扣成本；分钟基准按原报告的成本与市场规则计算。回测成交不代表券商成交。查看、播放和导出不会调用下单接口；本地 demo 使用券商替身。

## 本地启动与重现

```sh
cd web_platform
npm ci
npm run build
QUANT_DEMO_PORT=8791 node scripts/demo.mjs
```

打开 `http://127.0.0.1:8791/#replay`。构建直接使用提交的快照，无需网络重新抓取行情。需要重建日线课堂快照时，在仓库根目录运行：

```sh
.venv/bin/python scripts/prepare_low_frequency_data.py
.venv/bin/python web_platform/scripts/prepare-classroom-data.py
```

原始文件 SHA256：`8fe8d4ccf9d0fa9660b898d88c510ac71505b0907a6cef37989d3c0dc8fed8c5`。衍生快照只取 SPY 最后 750 根 OHLCV，保留来源 URL、复权方法和源文件摘要。
