# 页面响应与自研策略入口优化

只读排查发现目录接口阻塞首屏：校园入口在本机测得页面 8–31 ms、身份接口 8–13 ms，而策略目录连续两次 9,129 / 9,200 ms。数据库中有 2,148 份组合回测，payload 合计约 1.96 GB；旧查询反复定位每个策略的最新报告，并重复解析同一大 JSON。

优化先从轻量字段选择每个策略的最新 ID，再连接对应报告，一次 JSON 提取所有排序摘要。没有删历史、改数据库结构、缓存过期结果或改交易逻辑。178 个策略的完整接口返回值与旧实现逐项深比较一致。最新报告按创建时间及 ID 决定，原始研究来源与最新导入来源仍独立。

前端不再等目录加载完才显示页面及读取身份；同一时刻的重复目录请求合并，但完成后不缓存，下一次请求仍读取最新报告。账户首页、已有策略导航与策略表格增加第 2 组自研提示；按钮直接选中美股自研策略并滚动到完整流程，没有新增导航页面。

2026-09-21 22:08 上线后，同一路径连续三次目录接口 534 / 548 / 535 ms，较优化前约缩短 94%。这是服务器本机端到端测量，不代表其他校园设备的网络延迟。券商账户接口仍受各券商网络响应影响。

验证：225 项网页回归测试通过，构建和产物验证通过；浏览器验证首页提示、一键定位、默认选中与无脚本错误；上线后后端与内网入口健康检查均正常。未下单、撤单或重启守护任务。
