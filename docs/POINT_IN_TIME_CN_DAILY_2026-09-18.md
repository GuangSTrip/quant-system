# A 股全市场动态选股与日线买卖验证

本报告使用 2024-01-02 至 2026-09-17 的 658 个交易日。Tushare `daily` 按交易日取全市场行情，压缩保存 81.5 MiB；本地证券清单有 5904 个上市或退市代码。2024 年作为指标预热，2025 年作为开发段，2026 年至 9 月作为后续检验段。起始现金 100 万元人民币。

每次重选，仅根据当日及以前的信息，要求上市至少 180 日、当日有成交，并在当日成交额前 300 名中选股。收盘计算信号，下一交易日开盘模拟成交；买卖各收 15 基点，100 股整数手，成交量上限为当日成交量的 1%，买入后最早下一日卖出。除“趋势中回调”每五日重选外，其余每 21 日重选。收益按 Tushare `close/pre_close` 链接复权日收益。持仓现金未计利息。

下表是原始仓位的结果；回撤为正数幅度。

| 选股规则 | 2025 年化 / 回撤 | 2026 年化 / 回撤 |
|---|---:|---:|
| 成交额前五 | 64.57% / 31.59% | -3.16% / 41.21% |
| 半年相对动量 | -26.63% / 39.82% | -64.43% / 58.28% |
| 趋势加动量 | -9.37% / 29.16% | -57.73% / 55.19% |
| 接近年内高点 | 48.86% / 42.51% | 20.00% / 40.70% |
| 趋势中回调 | -19.05% / 42.88% | -58.70% / 59.73% |
| 低波动加趋势 | 12.18% / 7.72% | 9.64% / 11.20% |

低波动加趋势的 6% 波动目标仓位把两段回撤降至 4.50% 和 4.43%，但年化收益只有 4.84% 和 0.35%。其余波动目标和回撤刹车组合记录在 `reports/point_in_time_cn/report.json`。30 个规则组合中，**没有一个在开发段同时实现年化至少 8% 和最大回撤不超过 5%**；因此没有指定可宣称达标的最终策略。

这仍是研究回测：历史 ST 标签、涨跌停无法成交的情况、退市末日的强制处置、除权日真实可买股数和开盘滑点未完整建模。它们可能使实际结果更差。美股和港股的全市场历史数据尚未取得，网页显示未验证，不使用旧固定名单代替全市场结果。

行情接口说明：[Tushare A 股日线](https://tushare.pro/document/2?doc_id=27)。低波动候选参考 [Baker、Bradley、Wurgler 的低波动研究](https://pages.stern.nyu.edu/~jwurgler/papers/wurgler_bradley_baker.pdf)；该论文研究的是美股，应用于 A 股属于待验证的推断，并非收益保证。
