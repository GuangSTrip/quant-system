# 独立信息来源：A股盈利质量与估值

2026-09-22先登记后回测。价格反转/趋势替代方案未明显胜出，因此尝试真正不同的财务信息。不是对既有动量评分换权重。

数据采集阶段补充登记（尚未运行财务策略）：因2024年底以后接口反复无响应，本实验固定2015—2024十年价格区间，采用2014-12-31至2024-09-30的40个已完整执行查询的季度截面。2024年末观察日原本需隔下一交易日才进入信号，因此2024-12-31快照对这一截止区间没有影响。冻结数据目录data/own_fundamental_cn_2014_2024；旧策略按相同截止日期重算。未完成2025财务研究，不按收益选择截止日期。后段仅2024年，不能把它写成2024—2025结果。

历史来源：掘金`stk_get_finance_prime_pt`，明确指定原始合并年报`data_type=101,rpt_type=12`，每季度最后交易日查询当时最新公布报告，校验`pub_date<=asof`。不使用修订版报告填回历史。观察结果至少隔一个交易日才进入收盘信号。估值使用同日`stk_get_daily_valuation_pt`的`pe_ttm`；供应商历史TTM计算版本仍未独立复核。

初始股票清单沿用已收集沪深普通股；逐快照仅请求当时已上市、尚未主表退市的证券。交易候选依旧须具有价格预热和流动性，合格池取当时成交额前1500，再限制波动率≤75%。财报距离报告期超过550日则不用，关键字段缺失不填零。资产、归母权益、归母利润及经营现金流均须为正。金融业指标可比性不充分，是局限，不能称行业中性。

财务质量分数Q：归母净利润/总资产、归母净利润/归母权益、经营现金流/总资产三项横截面分位的平均。价值质量分数VQ：50%Q+50%正市盈率对应盈利收益率(1/PE)的分位；价值质量需要PE>0，纯质量不用PE。

固定4个候选：Q或VQ × 广度仓位控制开/关。持仓25只、逆60日波动率配重、单股≤10%、最高总仓位95%、目标波动率18%只减仓、每21个观察日调仓。不开个股动量或止损过滤。广度开启时使用前轮35%到70%线性仓位规则，借此区分财务选股本身和市场风险控制。

采用同一下一开盘、容量、开盘缺口、停牌与费用账本，全部费用计入。四者只按截至2020年既定开发期评分选择，保留其后2021—2023和2024—2025分段结果与成本/延迟压力。前期已看过全历史，不称未接触样本外。

目标仍20%年化、15%最大回撤，必须同时满足。数据和指标取得成功不代表策略已成功。长桥返回的港美财报样本只有财政期结束时间，尚未确认披露日期/历史可得版本，不能直接拿来复制本实验。
