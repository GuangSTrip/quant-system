# 日线替代策略交接（2026-09-17）

> 本文件记录最初的每市场单标的试验，表格是旧结果。港股和 A 股随后改为调整价格，研究也补充了动态选股与组合回测。**当前策略结论以 [动态选股与组合规则研究](DYNAMIC_STOCK_SELECTION_RESEARCH_2026-09-18.md) 为准。**

## 与本组员任务的关系

本文件是三市场分钟数据暂时不可得时的**日线替代研究**。日线策略不是高频策略，也不能用于证明原三种分钟策略有效。这里的代码只抓取数据、生成信号、回测和输出报告；不接券商、不提交模拟盘订单。

## 日线策略类别：三种固定规则

本次增加三种日线规则，均由 `scripts/evaluate_daily_strategy.py` 使用相同执行和成本模型在三个市场分别验证。参数是研究假设，当前没有按每个市场调参或从样本外挑选赢家。

| 规则版本 | 家族 | 收盘信号 |
| --- | --- | --- |
| `donchian_vol_v1` | 趋势突破 | 突破此前 20 日最高价且高于 80 日均线；跌破此前 10 日最低价或均线退出 |
| `time_series_momentum_v1` | 时间序列动量 | 60 日涨幅为正且高于 80 日均线；动量转负或跌破均线退出 |
| `short_reversal_v1` | 短期均值回归 | 3 日跌幅至少 3% 且仍高于 80 日均线；回到 5 日均线、跌破 80 日均线或持有 5 日退出 |

时间序列动量与波动率管理参考 [Moskowitz 等研究](https://faculty.som.yale.edu/tobymoskowitz/research/) 和 [NBER 波动率管理论文](https://www.nber.org/papers/w22208)。短期反转可参阅 [纽约联储相关研究](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr513.pdf)。这些文献仅提供研究动机，本实现不复制论文组合或结论。

## 第一种规则的执行细节

固定规则版本 `donchian_vol_v1`，详见 `scripts/evaluate_daily_strategy.py`：

1. 第 t 日收盘价高于此前 20 个交易日的最高价，且高于截至 t 日的 80 日收盘均线，形成买入信号。
2. 第 t 日收盘价低于此前 10 个交易日的最低价，或低于截至 t 日的 80 日均线，形成退出信号。
3. 信号于 t+1 交易日开盘价成交；只做多，空仓时才买入，持仓时才卖出。A 股买入后至少跨一个交易日才可能卖出。
4. 买入仓位上限 100%，按截至 t 日的 20 日已实现波动率目标年化 12% 缩小仓位，不使用杠杆。美、港、A 股单边成本假设分别为 10、20、15 基点；港/A 股按 100 股整手粗略计算。成本再翻倍单独报告。
5. 同期买入持有作为基准；70% 开发段 / 30% 留出段分别记账。留出段指标用之前的历史做指标预热，但不能用于调参。初始预算为各市场本币 100,000 元/美元/港元，**跨币种收益不合并**。

突破和波动率调整是待检验的经济假设，不宣称新策略优于基准。研究背景可参见 [AQR 趋势跟随研究](https://www.aqr.com/insights/research/journal-article/a-century-of-evidence-on-trend-following-investing) 和 [趋势规则比较](https://www.aqr.com/Insights/Research/Journal-Article/Which-Trend-Is-Your-Friend)。这不是论文参数的直接复现。

## 数据与当前状态

`scripts/fetch_daily_strategy_data.py` 先调用 AkShare 的 `stock_us_hist`、`stock_hk_hist`、`stock_zh_a_hist`；失败时调用 Tushare 的 `us_daily`、`hk_daily`、`daily`。美股两者均失败时，最后使用项目已有 Yahoo Chart 适配器。输出来源、调整口径、抓取时间、区间、质量计数、SHA-256 到 Git 忽略的 `data/daily/`。港/A 股未复权数据需检查拆股、分红和停牌；缺乏调整信息时，长期收益可能失真。Yahoo 美股数据为拆股与股息调整后的研究价格，不能直接视为券商实际开盘成交价。Tushare [A 股日线](https://tushare.pro/document/1?doc_id=27)为基础权限；[港股日线](https://tushare.pro/document/2?doc_id=192)需要单独开通权限，[美股日线](https://tushare.pro/document/2?doc_id=254)也需按账户权限核实。用户有积分不自动代表三市场权限全部可用。

本机重试三个 AkShare 日线接口，均被东财服务器断开。用户提供本地 Token 后，Tushare 返回港股和 A 股多年数据；美股原始日线及复权日线均提示该账户无接口权限，遂使用项目现有 Yahoo 适配器取得 SPY。港股第一次请求成功，后续立即重复调用会遇到每分钟 1 次的频率限制。所有数据来源与 SHA-256 见 `data/daily/*.meta.json`。

## 实际历史回测

2020-01 至 2026-09，固定规则、单标的、各自本币 100,000 初始预算。信号下一日开盘成交，持仓到区间末以末日收盘价估值，仍持有的股票未假设卖出。港/A 股原始价格没有计入股息及公司行动，因此它们的总收益只是价格策略近似，**不是完整投资回报**。全样本、留出样本及成本压力详见 `reports/daily_strategy/summary.json` 与逐市场 JSON。

## 运行步骤

在项目根目录的 PowerShell 中执行 `notepad data\tushare_token.txt`，将 Token 独占一行保存。`data/` 已被 Git 忽略，不要将 Token 贴进聊天、文档或命令参数。也可使用 `TUSHARE_TOKEN` 环境变量。

```powershell
conda activate quant-system
$env:PYTHONIOENCODING = 'utf-8'
python scripts/fetch_daily_strategy_data.py
python scripts/evaluate_daily_strategy.py
```

抓取成功后，查看 `data/daily/*.meta.json` 的日期范围、无效行、异常大跳空，再读取 `reports/daily_strategy/summary.json` 和逐市场报告。若部分市场接口无权限，脚本会逐一说明，不会填造缺失结果。下一轮应补复权/股息处理、更多标的和市场阶段、可成交性约束与滚动时间验证；只有留出收益、回撤和成本压力均可接受，才考虑将策略规则交给负责模拟盘的同学。
