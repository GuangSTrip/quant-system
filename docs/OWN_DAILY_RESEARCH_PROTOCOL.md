# 自研日线策略研究协议 v1

登记日期：2026-09-22。目标：CN/HK/US 独立账户、无杠杆、扣成本年化 ≥20%、最大回撤 ≤15%（挑战 ≤12%）。目标不是承诺，不能通过删除年份、剔除失败试验或修改统计口径达标。

## 研究假设及原创边界

拟研究“趋势质量—市场广度—相关性约束的自适应组合”。动量、趋势、波动管理是已有方法；本组贡献限于具体评分、联动机制、实现和验证，不宣称首创这些因子。

1. 长中短期趋势一致，且收益没有集中在少数几天的股票，可能比单纯涨幅排名稳定。
2. 市场内上涨股票比例下降时降低敞口，可能减少系统性回撤，但会错过反弹。
3. 根据候选股票共同波动约束组合，可能改善集中风险，但会牺牲强势行业收益。
4. 排名保留缓冲及最小交易阈值，可能减少成本，但会推迟换股。

各条均需单独消融检验；未验证前仅是假设。

## 时间与选择规则

首选数据 2014—2025；2014 用于预热。开发 2015—2020、验证 2021—2023、最终回溯评估 2024—2025。Alpaca 更早数据可能不可用，则报告实际开始日期，不拼接不同数据源冒充一致历史。全段不足八年不得声称满足长期要求。

先在开发期选参数；验证期仅报告，不依照最终期重选。既有项目看过部分后期结果，因此最终期称“回溯评估”，不是严格未接触样本外。保留全部试验编号、参数、成本、逐年表现与完整曲线。允许后续研究新版本，但重新登记且披露已看过哪些区间。

## 数据边界

优先官方 Alpaca SIP、长桥、掘金接口。仅查询行情与证券资料，不下单、不修改在线策略。保存原始证券清单、行情文件哈希、来源、实际覆盖、失败及空数据。

初始清单包含平台可返回的普通股及非活跃/退市证券；ETF、权证、优先股、基金等不混入选股。平台清单不是经独立审计的全市场历史清单。上市信息缺失、退市结算不明、港股历史退市名单不全、北交所覆盖不足均构成完整验证的阻碍。未完成清单覆盖审计前，研究结果只能标为探索。

不得根据整段未来涨幅或未来最大异常收益删除股票。异常只在当时触发停买/人工核验，已有持仓仍计价，不能抹掉亏损。无当日价格时不虚构成交；退市缺少结算价需列明损失敏感性。

## 回测记账

收盘产生信号，下一交易日开盘成交。只用截至信号日的数据计算排名、波动、流动性、市场广度。卖出后买入，现金不得为负，不做空，不加杠杆。缺价不能成交；停牌持仓继续占用资金。小额卖单的所得加现金不足以支付最低手续费时拒绝成交，不假设借款垫付费用。日收盘净值计算最大回撤，明确未包括盘中最深回撤。

初始资金每市场独立 1,000,000 本币，不换汇拼合收益。收益=完整策略净值增长，CAGR 按真实日期跨度，最大回撤=净值/此前最高净值−1，首日包含初始资金。闲置现金不假设利息。计提期末假想清仓成本，防止靠未卖持仓躲避卖出税费。

复权价格的研究账户用分数单位模拟公司行动，不能称为真实股数账本；最低费用可计入每笔，但整手、历史股数相关收费、真实退市结算未齐前不能称执行级回测。

## 成本与实验

佣金、交易税费、滑点分开记账；A股及港股印花税按日期切换。券商佣金档位不明时采用明确假设，不将模拟盘免费成交当作零成本。美股股数相关历史监管费用先用披露的保守成本预留，不能声称逐日精确复刻。基础成本、双倍全部成本、延迟一个交易日执行均报告；不可根据压力测试结果回头修改主候选后仍称独立验证。

比较同一股票池等权基准、纯动量、完整策略与去除质量/广度/相关性控制的消融版本；报告换手、费用拆分、每年收益、最差年份、敞口、停买原因、失效模式与逐笔成交。

## 判定

数值门槛与数据质量门槛分开。即使某版本年化20%且回撤15%，如果依赖当前幸存者池或历史不足，也只能叫“探索样本数值达标”，不能宣称三市场全股票池长期目标完成。
