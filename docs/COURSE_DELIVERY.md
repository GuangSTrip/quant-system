## 核心能力

| 环节 | 可交付行为 |
| --- | --- |
| 数据与回测 | 真实 IEX 完整日线、三种参数模板、指标与曲线、持久化快照与重放 |
| 启动 | 选择已保存回测、独立预算、确认文字；检查空仓、对账、全局开关及真实后台心跳 |
| 自动执行 | 后台计算日线信号、校验风控、生成并提交 Paper 限价单；关闭网页继续运行 |
| 去重与恢复 | 每日唯一决策、持久化订单意图、幂等 ID、并发租约、未知状态暂停 |
| 券商跟踪 | 同步订单终态与成交量，核对账户及策略持仓；不将委托接收显示成成交 |
| 控制与证据 | 暂停／恢复、申请撤销策略挂单、运行日志、决策快照、审计和原始回报导出 |

在线调度为 GitHub Actions OIDC；组员独立部署使用 Cloudflare 原生 Cron。调度有延迟，不承诺固定秒级响应。系统只连接 Paper，没有真实资金端点。自动策略为单标的整数股、只做多；无信号、持仓不需变化或休市时不下单。

## 课堂展示流程

1. 登录，查看账户、市场时钟和行情时间。在「风控与对账」对账并恢复模拟交易。
2. 在「策略与回测」运行一个模板，保存报告，展示参数与数据快照。
3. 在「自动策略」选择报告，设置预算，确认心跳新鲜，输入“启动自动模拟交易”。首次选定标的必须没有持仓和挂单。
4. 关闭网页，等待后台任务。重新打开后展示心跳、运行记录、信号、订单号和券商状态；需要现场检查时可点击「立即检查一轮」，此按钮执行同一真实 Paper 流程。
5. 在开市且信号产生订单后，持续查询券商结果。实际收到成交股数、价格和时间，再展示对账及证据导出。没有成交就如实标记等待。
6. 演示暂停及暂停后的阻断；结束前查看剩余挂单和持仓。暂停不自动平仓，撤单请求不保证取消已发生的成交。

[自动策略详细说明](../web_platform/AUTOMATION.md)；[手动执行与九项成交验收](../web_platform/COURSE_ACCEPTANCE.md)。手动订单验收不能代替自动策略成交证明。

## 接手与收尾

维护者先查看当前提交 CI，再按三步部署在自己的账户验证。部署保留独立网站与数据库状态，迁移只应用新增 SQL；恢复保护不需要新迁移。首次部署默认暂停，心跳不会自动授权交易。

开发环境连接故障已恢复，恢复补丁已构建、测试、推送并成功发布到原公开网址，网站与 GitHub 业务源码已同步。当前可以交付单账户日频自动量化 Paper 系统的代码、网站及部署说明。最终汇报若要声称“在线自动成交验收通过”，仍需在常规开市时保存真实自动委托与成交回报；市场休市时可展示真实后台等待流程。
