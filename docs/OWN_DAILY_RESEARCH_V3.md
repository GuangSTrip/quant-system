# 第三轮：可解释的在线学习评分

登记时间2026-09-22；已看到第一轮的三市场结果。继续作为探索研究，不能称全新未接触测试。

第二轮为固定评分的机制对照；第三轮增加与之独立的在线学习假设：价格特征有效性会随时间变化，使用已实现的历史横截面收益估计系数，可能比固定因子权重更合适。岭回归是已有统计方法；自研内容是特征定义、标签成熟门禁、与质量评分/广度风控的组合以及验证实现，不声称发明岭回归。

## 完整定义

八个输入均为当日合格池中分位数减0.5：63日动量、126日动量、252日动量、低下行波动、趋势路径效率、接近年内高点、5日收益接近−2%、低单日正收益集中度。

每21个市场交易日建立一个训练截面。标签为下一开盘买入至第21个交易日收盘的收益，限制到[−50%,50%]后减去该截面平均收益。只在下一开盘和标签结束日都有有效价格的训练样本上使用；因此缺失退市结算造成的训练选择偏差仍是局限，不能声称已消除幸存者偏差。

每21日重新训练，用最近756个交易日内、标签结束时间不晚于当日的截面；至少12个成熟截面且500条记录。公式为 β=(XᵀX+0.05N I)⁻¹Xᵀy。0.05固定，不根据后期最优选正则参数。训练不足则沿用预设固定质量动量评分，不凭空预测。

新股票评分=预测超额收益的分位数×α+趋势质量分位数×(1−α)，α比较0.65与1。预测的是相对排序，不是承诺的绝对未来收益。模型系数及每次训练最后成熟标签日期保存在model_updates.json，可逐次解释。

风险层沿用第二轮：广度下限25%、逆波动权重、10%收盘跟踪退出、20日冷静期；每21日换股。持仓15或25，目标波动18%或24%，两种混合比例，共8个固定配置。训练只用当时已经成熟的标签，不能把当天尚未发生的未来21日收益喂给模型。测试通过扰动未来价格验证过去系数不变。

仍仅按开发期评分挑主候选；验证期和2024—2025回溯结果照常披露。加上前两轮，本次累计固定配置预算为12+24+8=44个/市场，所有结果保留。观察到更好的全段结果不会替换开发期选出的版本。
