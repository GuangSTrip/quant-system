# 组合策略持仓归属与使用流程

## 页面流程
1. 选择市场和策略，直接阅读选股、买卖和资金分配规则。
2. 查看当前股票池的历史回测及逐日回放。
3. 查看最新信号选出的股票、名称和目标资金比例。
4. 输入模拟预算，读取账户与有效报价，再确认启动。
5. 查看执行状态和订单结果。

选股由策略负责。历史回测不是当前买入清单，预览不是已成交订单；休市不伪造实时股价。

## 持仓隔离
- 通过 artifacts 中 portfolio_ownership 类型、ownership:<run_id> 主键保存原有持仓基线，与 portfolio_runs 在同一数据库事务内创建。
- 原有委托未结束时，允许创建运行，但不提交策略委托。等待期间显示 waiting_existing_orders。所有原有委托结束后才冻结基线，随后开始策略交易；不会自动撤销原有委托。
- 策略拥有的数量仅来自该 run_id 的实际成交净额。每轮校验：账户总数量 = 原有数量 + 策略拥有数量。差异导致暂停，不能自动吸收不明变动。
- 同一股票可以有原有数量和策略数量。调仓和退出只针对策略数量，释放运行不再要求整个账户空仓。
- A股可卖数量保守扣除原有数量，避免用旧仓绕过新买入部分的 T+1。
- 旧版本运行因创建时要求空仓，缺少基线记录时按空基线兼容处理。
- 同一市场仍一次运行一个组合，保留网页手动下单互斥。启动后在券商终端进行额外交易或公司行动导致数量变化，会暂停等待人工核对。
- 预算是策略的独立资金上限，不会把原有股票市值算入策略权益。实际买入还受账户现金、交易限额、手续费预留和整手限制约束。

## 保留股票并结束策略（2026-09-21）
运行暂停且无未完成策略委托时，可明确确认“结束策略，保留股票”。服务核对账户与持仓归属后释放当前运行，审计记录保留移交数量，不提交卖单。剩余股票转为手动管理；启动下一策略时作为原有持仓基线保护。默认结束操作仍要求策略自有持仓为空。199项网页测试通过，包含确认、未完成委托拦截、移交审计及新策略基线验证；A股模拟账户实际移交成功。
