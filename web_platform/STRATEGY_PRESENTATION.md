# 策略讲解与课程展示

打开网站左侧「策略讲解」。本页把规则、价格和指标、逐日信号、历史回测以及模拟运行入口放在一起。

1. 首次打开使用明确标注的固定教学数据，访客也能调参学习。它不是 SPY 等证券的真实行情，数值不能作为策略盈利证据。
2. 选择双均线、绝对动量或买入持有，调整周期、回测仓位与单边成本，图形、收益、回撤和讲稿即时重算。计算直接复用服务端同一版本的研究引擎。
3. 点击价格图或拖动日期滑块，查看当日指标与信号理由；上下日按钮和方向键也可使用。三角形标记是回测成交日，信号使用前一完整日线；持有信号不等于每天买入。
4. 登录后选择标的与历史天数，点击「获取真实行情并保存回测」。也可点击「查看已保存回测」，选择报告后载入它的真实数据快照。
5. 在真实快照上继续调参，会显示未保存预览。改变标的需重新获取对应数据；改变历史天数不会重写已载入快照。点击「保存当前真实快照上的参数」生成独立报告。
6. 点击「带入自动策略配置」，系统选中刚保存的报告，但不会启动。仍需设置独立预算、对账恢复、确认后台心跳并授权启动。已经运行的策略不受本页改动影响。
7. 「汇报时，可以这样讲」跟随当前数据和参数更新；可下载 Markdown 讲稿，附参数、快照和报告编号。

回测图使用百分比仓位、下一日开盘价和设定成本；自动 Paper 使用固定预算、整数股限价单，实际结果可能不同。蓝色基准为同仓位买入持有且不计成本。调整慢周期会改变预热长度和评价区间，不能忽略样本差异。调参不等于样本外验证，券商委托也不等于已成交。

验证覆盖：图解均线不读取未来数据、动量窗口的准确端点及相等时空仓、参数调整改变结果、下一日开盘成交、买入持有单次建仓；原平台交易和故障恢复测试一并运行。
