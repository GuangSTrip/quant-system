使用说明 · 完整课堂流程

  1. 查看实时账户

    总览显示模拟净值、现金、购买力、市场时钟、账户历史与持仓。页面可见时每 15 秒刷新账户和订单；行情查询为按需更新，行情时间可能早于读取时间。

  2. 登录操作员

    左下角“登录以操作”使用站点所有者的 ChatGPT 账号。公开访客可查看；交易与风控按钮只对绑定的操作员开放。

  3. 启用交易

    进入“风控与对账”，检查限额并点击“对账后恢复模拟交易”，输入“恢复模拟盘”。初始化默认为暂停。

  4. 研究策略

    在“策略与回测”选择标的、模板、周期、仓位和成本，运行真实 IEX 历史日线回测。每份报告保留数据快照；勾选重跑可以验证复现。

  5. 从计划到订单

    点击“生成模拟订单计划”，查看当前与目标仓位差异。计划 5 分钟内有效。它不会自动下单，提交时还会再次检查风控。

  6. 手动提交

    也可在“模拟交易”填写标的、整数股数、类型和价格。点击预览后核对摘要，再确认提交 Paper 订单。休市时仅可明确允许限价单排队；有委托不等于已成交。

  7. 撤单与对账

    订单列表可撤销本平台创建的未完成订单。撤单中需继续刷新确认。状态未知时先对账，不要换一个订单号反复重发。

  8. 演示熔断

    风控页可暂停新增订单，或暂停并申请撤销本平台未完成订单。这是真正的服务器控制，不再是浏览器演示开关。

推荐课堂顺序：登录 → 查看行情 → 对账并恢复 → 回测 → 生成计划或手动小额限价单 → 提交 → 查看券商订单状态 → 撤单／对账 → 暂停。是否成交取决于市场时段、限价与 Alpaca 模拟撮合。

此版本不运行后台自动交易，不执行任意策略代码，不覆盖助教文档的高频、机构多租户、AI编排和真实资金模块。暂时没有订单或持仓可以是正常状态。
