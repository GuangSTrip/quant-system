## 新手使用顺序

1. **账户首页**：登录并查看三个市场的资金和持仓。
2. **选策略 · 开始模拟**：选市场和策略，看规则、历史回测、决策回放及具体股票名称。
3. **设置预算**：读取最新信号与报价，确认买哪些股票、各买多少股，再授权模拟执行。
4. **运行中的策略**：查看运行或等待原因，到订单页核对券商回报。
5. **结束模拟**：暂停后平仓退出；A 股当天买入受 T+1 限制，可按页面流程结束策略并保留股票。

历史回测不等于当前买入建议；提交委托不等于成交。实时执行仍检查交易时段、报价有效性、现金、整手与限额。原有手动持仓与策略持仓独立记账。

## 开发验证

Node.js 24；Python 研究与券商 SDK 分环境管理。

```sh
cd web_platform
npm ci
npm run build
npm test
npm run validate
```

Python 研究测试：在根目录安装 `python -m pip install -e .` 后，执行 `python -m unittest discover -s tests -v`。SDK 跳过项不能视为外部连接通过。

仓库包含源码、数据库迁移、公开研究快照、配置示例、测试和演示视频；不包含券商凭证、网站密码、证书私钥、账户数据库及私有日志。全新克隆需自行配置模拟账户。

旧研究与云端部署说明保留于[历史研究 README](docs/RESEARCH_README.md)等文档；当前交付以本页和最终交付说明为准。
